# 灰色测试框与人工测距

0.3.0版保留具体等待原因，并取消人工距离的30秒强制失效。两个灰框且左右按钮不能点击，表示尚未满足显示/作答条件，不能据此判断近视程度。

1. 先在“距离”页打开“查看条纹显示示例”。左边应显示放大的条纹，右边为灰色。示例不需要测距，不记录作答，也不计算度数。
2. 返回正式测试，阅读“请到距屏幕 … 厘米的位置”。用尺子或卷尺实际测量受测眼到屏幕平面的距离，移动到提示的范围内。
3. 在“距离（厘米）”中填写实际值，如实填写测量误差，然后点击“确认已实测，并保持不动”。输入文字本身不等于确认；人工模式不会自动发现用户已移动。
4. 保持设备和身体不动。读数稳定后会显示条纹，观察片刻后按钮启用。固定位置的确认不会按时间重置。每次移动、目标距离改变或中断后，需要重新实测、填写并确认；点击确认会自动收起键盘，也可使用键盘上方“完成”按钮。

不要直接把目标数字当作实测值填入，也不要缩小误差数值来绕过检查。没有真实的距离参照时，可以看示例，但不能继续计算屈光度数。

页面会区分：尚未确认、无效输入、目标距离改变、未到目标距离、等待稳定、像素不足和测试区域不足。像素或显示区域异常时应停止本轮并重新检查屏幕校准。

本修正改善显示状态与操作提示，不证明人眼屈光度测量准确；仍需专业验光对照。

练习条纹现在比正式任务宽6倍，圆形区域也更大。练习仅帮助理解操作，不计入度数拟合。若仍无法辨认，可点击“我仍无法辨认练习图案”结束并保留原因；放大练习并未扩大正式任务的已验证范围。

## 0.3.1 内屏拿远时的校准保护

设备重力姿态的unknown/face-up/face-down变化不会触发尺寸重校准；短暂移除后重新挂载视图、同一显示区域一物理像素内的舍入抖动也不清除校准。实际屏幕、缩放、原生像素或窗口区域变化仍重新检查。真实界面旋转90°但尺寸未改变时，会停止当前方向测量、要求确认距离，保留蓝线尺寸校准。

把设备拿远时仍需保持头部与屏幕方向对齐。测试目标距离改变时，人工距离需要重新实测确认；这与重新测量蓝线是两件不同的事。

## 中文

视界研究版 0.4.0（build 8），支持 iPhone 和 Mac。

- 新增简体中文、英语、法语、西班牙语、俄语和阿拉伯语界面，默认跟随系统，也可在应用内切换。
- 阿拉伯语界面采用从右到左排版，测试图案和左右作答按钮保留物理左右位置。
- 本机语音词表随界面语言切换；没有对应的本机识别模型时提示使用按钮或键盘。
- 数字输入接受逗号小数点及阿拉伯-印度数字；中文显示度数，其他语言使用屈光度 D。
- JSON 新增可选的 `interfaceLanguage`，保留旧记录的眼别编码。补充本地化检查、安装包资源验证和 GitHub Actions。
- 收紧译文格式占位符的整数宽度检查，清理打包临时目录，统一源码运行时记录的版本号。

附件：`VisionMeasure-0.4.0-macOS-arm64.zip` 为 Apple 芯片 Mac 应用（临时签名，未公证）；`VisionMeasure-0.4.0-source.zip` 为源码和验证工具；`SHA256SUMS.txt` 用于校验附件。iPhone 请使用 Xcode 选择自己的开发团队签名安装，不提供通用 IPA。

已通过 55 项核心测试、31 项 Python 测试、4 项 iPhone 模拟器界面检查、249 个键的五语言译文检查和 Mac 发布包校验。原生构建、模拟器结果和现存布局警告见[检查摘要](https://github.com/chen-bliss/vision-measure/blob/v0.4.0/Docs/Verification-summary.md)。六语言语音识别尚未逐一真机验证，译文尚未经各语言母语视光专业人员审校。临床有效性仍为 `NOT_ESTABLISHED`；研究估计不能用于配镜。

## English

VisionMeasure Research 0.4.0 (build 8) for iPhone and Mac.

- Adds Simplified Chinese, English, French, Spanish, Russian and Arabic interfaces, with system-language selection and an in-app menu.
- Uses right-to-left Arabic layout while preserving the physical sides of stimuli and answer buttons.
- Selects on-device voice vocabulary for the interface language; unavailable language models prompt users to use buttons or the keyboard.
- Accepts decimal commas and Arabic-Indic digits. Chinese displays powers in 度; other languages use diopters.
- Adds optional `interfaceLanguage` metadata while retaining legacy eye codes, plus localization checking, bundle verification and GitHub Actions.
- Tightens printf integer-width checks, cleans packaging staging directories and records the current version in source-built sessions.

Assets: `VisionMeasure-0.4.0-macOS-arm64.zip` contains the ad hoc signed, unnotarized Apple-silicon Mac app; `VisionMeasure-0.4.0-source.zip` contains source and validation tools; `SHA256SUMS.txt` checks asset integrity. Build and sign the iPhone app with your own developer team in Xcode; no generally installable IPA is included.

Passed 55 core tests, 31 Python tests, four iPhone simulator UI checks, checks for 249 keys across five translation tables, and Mac release-bundle verification. Native build results, simulator scope and the remaining layout warning are in the [verification summary](https://github.com/chen-bliss/vision-measure/blob/v0.4.0/Docs/Verification-summary.md). Physical voice recognition has not been verified separately for all six languages, and translations have not been reviewed by native-speaking eye-care professionals. Clinical status remains `NOT_ESTABLISHED`; research estimates are not prescriptions.

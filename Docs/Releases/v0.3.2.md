## English

VisionMeasure Research 0.3.2 (build 7) for iPhone and Mac.

- Fixes voice answers working only once: fresh listening for each ready trial, repeated identical answers, stale-result protection and recovery from short interruptions. The user has reported normal current operation.
- Includes display-calibration stability fixes, manual-distance and keyboard improvements, coarse practice, the app icon, and adjustable-size Fourier-precompensated patterns with PNG saving.
- Adds Chinese and English READMEs, professional-refraction comparison tools and independent distance-validation tools. The application UI remains Chinese.

Assets: `VisionMeasure-0.3.2-macOS-arm64.zip` contains the ad hoc signed, unnotarized Apple-silicon Mac app; `VisionMeasure-0.3.2-source.zip` contains source and validation tools; `SHA256SUMS.txt` provides file checksums. Build/sign the iPhone app in Xcode with your own developer team; no generally installable IPA is provided.

Verification: 47 core checks passed, including nine voice-routing cases, plus a passing focused manual-distance UI recheck. The initial keyboard timeout and remaining limits are documented in the repository summary. Physical voice success is user-reported feedback. Clinical validity and prescription-level refraction accuracy remain unestablished. Research records, credentials and signing material are excluded from the source release.

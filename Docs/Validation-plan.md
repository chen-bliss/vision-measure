# 第三级目标与验证方案

目标是利用设备自带屏幕、摄像头及可选麦克风，测量左右眼球镜、柱镜与轴位，并通过真实、独立的专业验光对照建立适用范围和准确性证据。

当前没有专业验光对照数据。**本原型的临床有效性未建立，不应被描述为准确验光、可替代验光师或可直接配镜。** 用户已选择先完成应用与验证工具；完整第三级目标仍待真实验证。

## 依据与本原型的区别

研究已有不依赖外接光学附件、通过视觉辨认远点和手机摄像头估距进行屈光测量的方案。例如 [Luo 等，2024](https://pubmed.ncbi.nlm.nih.gov/39494876/) 和 [Salmeron-Campillo 等，2025](https://doi.org/10.1111/opo.13560)。后者的主要验证对象为诱导的残余屈光误差，不能直接外推到所有裸眼度数、人群和设备。

本应用采用自己的左右条纹辨认、六方向重复边界与规则散光拟合流程，**并非上述论文方法的已验证复现**。不能把论文准确度当成此应用准确度。条纹辨认边界还受到调节、瞳孔、视觉神经处理、图案窗口、屏幕色彩和显示采样的影响，把它换算为光学远点本身就是需要验证的假设。

## 已实现的实验协议

版本 `farpoint-grating-0.1.0`，研究数据的算法和构建版本应在正式验证前冻结并记录源代码 SHA-256。

应用0.2增加了显示场景、物理姿态及应用版本记录。数值拟合方法未改变，但对照验证必须按显示环境和应用版本分组；未记录显示环境的旧会话不能用于宣称内外屏均已验证。

1. 成年受试者、单眼、裸眼；同伴眼轻遮，不按压眼球。个人匿名编号与测试眼分别记录。
2. 实测200逻辑点蓝线的物理长度，获得逻辑点/毫米；记录屏幕像素缩放。图案每条明/暗带角宽为1角分，即30 cycles/degree；圆形渐隐窗口直径为0.28°。
3. 最近距离至少20厘米，并进一步要求每带不小于1.6个物理像素；最近距离随屏幕而变。最远距离3米。界面空间不足时不显示可作答状态。像素门槛是初步工程选择，不能代替显示测量与视觉验证。
4. 八次练习至少七次正确。0.3.0起练习条纹宽6角分、区域直径1°；正式任务仍为1角分、直径0.28°。每次作答记录实际图案参数，练习（repeatIndex=-1）不参与度数拟合。方法记录版本为farpoint-grating-0.1.1。正式任务随机选择左右其中一侧显示条纹，另一侧为同均值灰色；渐隐边缘用于减弱轮廓提示。目标方向依次覆盖0、30、60、90、120、150°的光学子午线，条纹与受测子午线垂直。顺序随机，各方向重复两轮。
5. 每位置16次判断，13次及以上正确归为可辨认。先验证近侧可辨认、远侧不可辨认；若出现超量程端点，增加一组复核，避免一次幸运猜中就停止。
6. 在正的观看光焦度 `q = 1 / d` 区间二分，直至清晰/模糊边界的宽度不超过0.125 D。方向的研究屈光量取区间中点的负值。没有两侧边界不外推，也不报告零度。
7. 模型 `R(θ) = M + J0 cos(2θ) + J45 sin(2θ)`。负柱镜表示下：`S = M + sqrt(J0² + J45²)`、`C = -2 sqrt(J0² + J45²)`、`A = 0.5 atan2(J45,J0)`（模180°）。
8. 六方向各两次；最大重复差不得超过0.50 D，模型残差不得超过0.25 D；边界、范围、距离误差或数据不足时不出结果。低散光或轴位不稳定时隐藏轴位。以上均为待验证的工程门槛。
9. 距离或姿态不可靠时暂停显示；至少稳定0.8秒后显示图案，显示至少0.8秒后才接受答案。记录每次实际距离、来源、误差估计、目标距离、方向、答案、正确项和反应时间。

完整流程可能超过半小时，尚不适合直接作为快速消费者验光体验；疲劳会影响数据，应记录退出和失败，不应强迫完成。将来若缩短流程，缩短后的流程要重新验证。

## 测距方案与局限

- 深度：只在存在前置深度硬件、实际收到深度帧且人脸跟踪正常时启用。记录相机坐标下的眼部深度，采用保守误差下限。此误差下限未经本机型实测证明，摄像头到屏幕平面的偏移、姿态与真实视线距离仍需量具对照；不能因为收到深度数据就宣称准确。
- 普通摄像头：以个人在已知距离下的脸部投影尺度作为参考，在第二已知距离核验，拒绝使用平均脸宽/平均瞳距。核验相对误差需≤3%，姿态变化、摄像头/格式变化或校准超过30分钟时失效。只在两个校准距离之间使用。两点核验不能证明区间内的绝对精度，应在额外距离用量具验证。
- 人工：实测受测眼到屏幕平面的距离，明确估计误差；每次移动后重新输入。0.3.0起固定位置的确认不按时间失效；目标距离改变、模式/显示改变或应用中断后清除。原始确认时间戳保留，不伪造新测距时间。无法持续检查用户头部是否移动，因此仍须在有人监督的对照试验中单独验证。
- 统一：距离标准误差换算的屈光误差超过0.15 D时拒绝；不把共同的校准误差按重复次数开方缩小。只有“人脸检测成功”或主观臂长估计时，不生成厘米数和度数。
- 设备运动、屏幕缩放、目标显示方向及光照有独立影响；当前没有实现可证明的照度计或眼睛调节控制，需记录人工条件。

苹果说明 [Vision 人脸关键点为相对坐标](https://developer.apple.com/documentation/vision/faceobservation/landmarks2d)。本机语音只有在同时支持 `supportsOnDeviceRecognition` 并要求 `requiresOnDeviceRecognition` 时运行；否则提供键盘或协助者方式。[苹果文档](https://developer.apple.com/documentation/speech/sfspeechrecognitionrequest/requiresondevicerecognition)

## 已发现的工程证据

固定随机种子261025，三类模拟观察者各40例。真值独立按 `S + C·sin²(θ-A)` 产生方向屈光数据，再由作答搜索与拟合恢复。所有会话标为 `SYNTHETIC_MODEL`，临床证据标识始终为 `NOT_ESTABLISHED`。

初始每位置8次的方案受到幸运猜测影响，带随机噪声的40例中仅16例完成。改为16次判断并对超范围端点复核后，本次固定模拟中38例完成。该优化只说明工程逻辑有所改善，不能说明真人准确度或完成率。

在另一个人为加入0.65 D持续调节偏差的场景中，仍有34例能完成，球镜平均绝对误差约0.65 D。**说明算法可以稳定地产生有系统偏差的结果，当前质量门槛无法排除该情况。** 这也是不能声称已达到第三级的实证原因之一。模拟曲线参数是人工假设，不能代替人眼调节实验。

## 正式验证前需要冻结的方案

与具备资质的验光人员共同确定适用人群、验光参考标准、调节控制方案和研究同意流程。先做监督下的探索性可用性研究，修改方法后冻结版本，再招募独立验证人群。探索集和验证集不可共用受试者。

建议工程预设目标（不是医学标准或临床审批要求）：

- 至少50名独立验证受试者，并按预先计算的样本量和预期一致性界限进一步确定人数；50不是充分有效性的保证。
- 球镜、柱镜、球镜等效各至少90%的误差在±0.50 D内；球镜等效95%一致性界限在±0.75 D内。
- 至少15名参考散光≥0.75 D者评估轴位，至少90%的轴位差≤10°。低散光不使用轴位误差主导结论，应看J0、J45。
- 至少30名完成两次独立全流程，参考屈光未变化；球镜等效重复性系数 `1.96·SD(第二次−第一次)` ≤0.50 D，同时报告均值差。
- 明确每个目标机型、系统、显示设置和测距方式的验证范围；不能用一种 iPhone 代替所有 iPhone，更不能代替 Mac。各设备分层至少20人作为初步工程门槛。
- 验证集同时覆盖 iPhone、Mac，以及人工、个人校准摄像头、深度三种已发布测距方式；不能验证的方式继续只作为研究功能。
- 把不出结果、超量程、未完成、主动退出作为完整样本的结果报告；目标失败率≤10%，不能仅在成功者中宣传准确度。
- 外部验光者不知道应用结果。用同日专业主觉验光作为主要参考；是否需要睫状肌麻痹验光由专业人员和研究方案决定，不在应用中指导用药。
- 报告偏差、平均绝对误差、95%一致性界限、±0.25/0.50 D比例及区间，进行距离、屈光范围、散光、年龄、设备和测距方法分层。不能用高相关系数代替一致性。

真实样本达到数值门槛后，还需要核实数据来源、实验执行、适用范围和临床意义；分析工具不会把数值通过自动称为“已临床验证”。

## CSV 列说明

每行对应一个导出会话，全部必填：

| 列 | 内容 |
|---|---|
| session_id | 应用导出JSON里的id |
| participant_id | 与participantID完全一致的匿名编号 |
| eye | R/OD/右眼，或L/OS/左眼 |
| ref_sphere | 专业验光球镜，D，保留正负号 |
| ref_cylinder | 专业验光柱镜，D；支持正柱镜自动转为等价负柱镜 |
| ref_axis | 0至180°；零散光仍填0，不用于轴位比较 |
| reference_method | 主分析使用subjective；其他方法仅作为另行探索，当前不会混入主分析 |
| examiner_masked | 参考验光者是否不知道应用结果：1/0 |
| same_day | 应用测量与专业验光是否同日：1/0 |
| cohort | development或validation；禁止同一受试者跨组 |
| synthetic | 模拟数据填1，真实数据填0；工具也检查应用的模拟标记 |

准确性分析预先选择每眼最早会话，每人优先右眼、无右眼才选左眼；不挑选更准确的结果。重复性分析只选同日、同设备、同算法、同图案参数、同测距来源且参考值不变的前两次，每人一眼。

真实 iPhone/Mac 多距离测距精度与显示测量、真机权限及摄像头中断检查、真实受试者体验、专业验光对照、独立验证样本。尚无这些证据，第三等级目标不能标记为完成。

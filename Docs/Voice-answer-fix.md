# 0.3.2 连续语音作答

用户报告：第一轮“左边／右边”有效，第二轮起不再响应。

旧实现用关键词在整段转录中的字符位置去重，并带一秒全局冷却。系统修订或重置短句时，下一次同词可能仍在同一位置；在图案就绪前识别的词也会被消耗。识别错误直接停止，最终结果虽然新建任务，却没有统一释放旧请求。

本版移除跨轮字符位置和固定冷却。每个图案使用独立标识，图案就绪时重新建立本机识别任务，丢弃上一轮及等待期音频。每轮最多接受一次答案；重复部分结果、最终结果不能推进下一轮。系统正常结束后重新监听，短暂错误最多自动恢复三次，持续失败明确提示重新开启。取消、关闭、离开前台后的旧回调与延迟重启由代际标识拒绝。距离过期拒收的答案可在重新确认距离后再说。

“停止”不受图案就绪限制。界面分别显示等待图案、正在听答案、恢复中和不可用。语音仍仅在设备支持本机中文识别时开启，不切换云端、不保存音频或转录。

9项确定性检查覆盖连续8轮同词、连续8轮交替、旧回调、等待期、任务结束/错误重建、停止、距离拒收重试和无关文本。它们验证指令路由，不代表真实麦克风识别通过。真机请在图案就绪、按钮可用后连续复试至少5轮，并尝试“停止”。

API生命周期参考：[Apple recognitionTask](https://developer.apple.com/documentation/speech/sfspeechrecognizer/recognitiontask(with:resulthandler:))、[Apple SFSpeechRecognitionTask](https://developer.apple.com/documentation/speech/sfspeechrecognitiontask)。

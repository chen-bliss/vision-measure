# 真机测距核验

这是达到第三级之前的硬件检查。它回答“应用显示的距离是否接近独立实测距离”，不回答“验光度数是否准确”。目前没有真实核验数据，不能据此声称测距或验光已验证。

## 采集方法

1. 在准备验证的 iPhone 或 Mac 上运行应用。记录具体机型、系统、显示设置和摄像头设置；保持自动构图和变焦关闭。先选正常照明、正视、稳定姿态，条件记为 `frontal_stable`。
2. 由协助者用尺子或卷尺独立测量受测眼到测试图案位置的距离，并记录量具与定位的误差。不能用应用自己的读数作为参考距离，也不能用估计臂长。
3. 普通摄像头按应用流程完成个人两点校准。将这两个实测点记录为 `calibration`。每个人、每次重做校准用不同的 `calibration_id`。
4. 在两个校准点之间选取至少五个未用于校准的测试位置。每个位置三次独立重新就位，分别记录真实距离、应用读数和应用显示的误差估计。建议先测每台设备、每种测距方式至少三个人；这是初步工程检查，不是足够临床有效性的样本保证。
5. 应用不显示有效距离时，将 `status` 写为 `unavailable`；主动拒绝读数时写为 `rejected`。保留实测参考距离，读数两列留空。不要删掉失败记录或填写推测数值。
6. 倾斜、暗光、遮挡、更换摄像头等条件应使用不同的 `condition` 分开分析。只能把预先声明的可用范围用于主分析；范围之外的拒绝行为另行检查，不能说这些距离已经验证。

人工测距模式也需要检查：由一个人按日常使用方式输入距离，另一个人独立核验其真实值，不能把同一次尺子读数复制为两列后视作精度证据。

## 表格与命令

`distance-reference-template.csv` 是空白采集表。单位全部为米；毫米需除以1000，厘米需除以100。例如50厘米输入0.50，5毫米输入0.005。

| 列 | 内容 |
|---|---|
| observation_id | 每次观察的唯一编号 |
| participant_id | 匿名编号，不填写姓名 |
| device | 具体机型及系统，例如从应用记录复制，不使用笼统“手机” |
| source | manual、calibratedCamera 或 depth |
| condition | 采集条件，例如 frontal_stable；不同条件分开统计 |
| calibration_id | 个人本次校准编号；深度/人工模式也按独立测试批次编号 |
| role | calibration 或 verification |
| reference_m | 协助者独立实测的距离 |
| reference_bound_m | 参考距离的正误差范围，不能填0或假定完全准确 |
| observed_m | 应用显示的读数；无有效读数时留空 |
| observed_bound_m | 应用显示的误差估计；无有效读数时留空 |
| repeat_index | 同一位置的重复编号，0、1、2…… |
| status | ok、unavailable 或 rejected |
| synthetic | 真实数据0，模拟数据1；编号以SYNTHETIC开头也会标为模拟 |

生成空表和分析：

```sh
python3 Tools/validate_distance.py --template Docs/distance-reference-template.csv
python3 Tools/validate_distance.py collected-distance.csv --out Build/distance-validation
```

打开 `distance-report.html`。JSON报告保留逐条误差、失败数量、距离覆盖和重复性。

## 报告如何解释

距离误差以 `1/应用读数 − 1/实测距离` 换算为光焦度差。例如20厘米附近偏差1厘米，对应的光焦度差约0.24D（通常所说的24度）。因此不能只看平均相差多少厘米。

主准确性分析排除本人的校准位置，使用另外的验证位置。无法读数的记录保留在完成率分母。参考尺子测量的误差也计入每条最坏光焦度误差；若参考本身太粗，不能声称应用准确。

初步工程门槛包括：每设备、每方式、每条件至少三个人/三次个人校准；每次至少五个未用于校准的位置、各三次；至少90%可取得有效读数；至少95%误差（含参考误差）不超过0.10D，最大不超过0.25D；均值偏差不超过0.05D，重复范围不超过0.10D。普通摄像头还需要两点成功校准的记录。这些是预设工程目标，不是医学标准；真实研究前仍应由专业人员审查。

工具始终保留 `hardware_accuracy_established: false` 和 `clinical_validation: NOT_ESTABLISHED`，因为它无法核实尺子是否独立测量、样本是否完整、姿态是否如实记录。即使数值门槛满足，也要结合原始记录和实际执行进行外部审查，再开展验光准确性对照。

# 趣味视觉实验（0.3.1）

本页按用户提供的度数生成预处理图，再以相同大小、相同位置切换原图与预处理图。不是验光、视力表、治疗或已验证的眼镜替代方案。

## 使用

1. 用尺子校准屏幕尺寸。
2. 输入已有负柱镜处方中的近视和散光度数：例如球镜-3.00D填300，柱镜-1.00D填100；轴位按处方填写。不是正柱镜处方的直接输入界面。
3. 实测观看距离，选择文字（最多4字）、爱心或箭头。分别体验一只眼，避免把两眼不同度数混为一个输入。
4. 调整“字体／图案大小”滑杆（图案占画布40%至90%），再点击生成。文字和图形按真实字形边界等比居中，大小变化会重新做预处理。
5. 生成后切换“原图/预处理”，按裸眼实际感受比较。处理强度可调；改参数或实际显示环境后重新生成。
6. 用“保存到文件”导出预处理PNG；iPhone可点“保存到相册”，届时只请求添加照片权限。无论当前显示原图还是预处理图，保存按钮保存的都是处理后的图。

瞳孔直径默认3毫米，仅为可调整的假设，不是摄像头测得。输入和生成图仅保留在当前页面，不写入屈光测量记录。

## 算法与局限

使用简化的几何椭圆模糊核。近视/柱镜两个主子午线、轴位、距离、假定瞳孔和图案实际毫米尺寸参与计算；采用一个理想化的球面调节假设，未测量真实调节或高阶像差。

目标图在sRGB与线性亮度间转换。对线性灰度图作二维FFT，乘以有正则化的逆传递函数，再作IFFT；结果限制在屏幕可以显示的0至1亮度内。使用零填充减轻边缘环绕，保留180°轴位等价性。强度为0时保留原图；输入、尺寸异常或模糊范围超过画布能力时报告原因。

这是一种有界的傅里叶域预处理实验。并非“只做逆傅里叶变换就能矫正近视”：屏幕不能显示负光强，消失的空间频率也不能可靠恢复。对比度损失和光晕可能让结果比原图更难辨认。研究曾为改善这些限制引入多层或光场硬件，但本应用仍只使用普通屏幕。[Berkeley多层显示研究](https://graphics.berkeley.edu/papers/Huang-COA-2012-11/index.html)、[计算光场显示研究](https://www.computationalimaging.org/publications/eyeglasses-free-display-towards-correcting-visual-aberrations-with-computational-light-field-displays-siggraph-2014/)

模型内再模糊误差下降，只证明同一个假设模型内的数值行为。不能用它证明真实用户裸眼更清晰；这里没有收集真实视力改善证据。

代码：`Sources/RefractionCore/VisualPrecompensation.swift`、`Sources/VisionMeasure/FunVisionView.swift`。数学检查覆盖原图保持、同模型误差、轴位变化、亮度上限和异常输入。

## 保存与重新查看

PNG包含实际生成像素和当时显示宽度对应的DPI，不附加处方、姓名或设备标识等元数据；用户输入的文字会作为图像内容保留。图片是256×256像素，不含页面按钮和说明。文件导出使用系统保存面板，保存到相册使用PhotoKit的add-only授权；拒绝相册权限时仍可保存到文件。

相册和其他看图软件可能忽略DPI并自动铺满屏幕，这会改变预处理所假设的物理尺寸。请参考页面显示宽度，用相同屏幕尺寸与观看距离查看；保存本身不保证离开应用后仍有相同视觉效果。
